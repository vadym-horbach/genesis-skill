# genesis-skill

Claude Code skill `genesis`.

## Install

```sh
git clone git@github.com:vadym-horbach/genesis-skill.git ~/.claude/skills/genesis
```

Project-level install: clone into `.claude/skills/genesis` inside the project.

## Structure

```
SKILL.md        skill definition (frontmatter + instructions)
references/     docs loaded on demand
scripts/        executable helpers
assets/         templates and static files
```
